# نبض الأسرّة — Nabd

منظومة تفاعلية لمتابعة الطاقة الاستيعابية والإشغال في مستشفيات محافظة المنيا.

**فكرة وتصميم وتطوير: د. سامح ماجد صابر**

- لوحة إدارة لحظية لكل المستشفيات
- جناح افتراضي ثلاثي الأبعاد يرسم كل سرير بحالته
- بوابة لكل مستشفى بحساب خاص يحدّث منها السعة والإشغال
- قاعدة بيانات وتسجيل دخول على Firebase، والصلاحيات في `firestore.rules`

| الملف | الوظيفة |
| --- | --- |
| `index.html` | الموقع كله |
| `config.js` | إعدادات Firebase وإيميل مدير النظام |
| `seed.js` | بيانات الـ10 مستشفيات الأولية (تتستورد مرة واحدة من لوحة الإدارة) |
| `firestore.rules` | صلاحيات قاعدة البيانات |
